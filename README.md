# Plataforma web y móvil para el alquiler de herramientas, maquinaria y personal de construcción

## Nombre
Integrante 1: HUAMANI TUDELANO JHON SAMUEL

## Descripción
Aplicación web y móvil que centraliza y automatiza el proceso de alquiler de herramientas, maquinaria y personal de construcción: catálogo con disponibilidad, cotizaciones en PDF, direcciones de entrega en mapa, historial de contacto con el cliente y seguimiento del estado del alquiler.

## Caso de estudio
Empresa de alquiler de equipos y personal de construcción en Ayacucho, Perú.

**Caso de negocio (Ejercicio 02):** el sector construcción depende del alquiler de equipos y personal por periodos cortos, pero la gestión de cotizaciones, entregas y contactos se hace de forma manual (llamadas, WhatsApp, cuadernos o Excel). Esto genera:

- Dobles reservas por falta de control de disponibilidad.
- Cotizaciones calculadas a mano y lentas.
- Direcciones de entrega y datos de clientes perdidos o desordenados.
- Ausencia de historial de contactos y conversaciones.
- Poco seguimiento del estado de cada equipo alquilado.

**Catálogo de la empresa**

| Categoría | Ejemplos |
|---|---|
| Herramientas | Winches eléctricos, generadores a gasolina y monofásicos, trompos eléctricos, rotomartillos, tablas y encofrados |
| Maquinaria | Mixer, Carmix, excavadoras |
| Personal | Personal instantáneo (operarios, maestros, peones) |

**Fuera del alcance inicial:** GPS/IoT, marketplace de terceros y predicción de demanda.
