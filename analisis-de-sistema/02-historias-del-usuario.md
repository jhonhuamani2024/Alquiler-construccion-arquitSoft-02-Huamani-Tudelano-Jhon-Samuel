# 02 – Historias de usuario

Formato: **Como [actor], quiero [acción], para [beneficio].**

| ID | Historia de usuario |
|---|---|
| HU01 | Como cliente, quiero consultar el catálogo de equipos, personal y su disponibilidad por fechas, para elegir lo que necesito para mi obra. |
| HU02 | Como administrador, quiero registrar y editar equipos y personal con sus fichas técnicas y fotos, para mantener el catálogo actualizado. |
| HU03 | Como vendedor, quiero generar una cotización en PDF con número correlativo y vigencia, para responder rápido y sin errores de cálculo al cliente. |
| HU04 | Como vendedor, quiero convertir una cotización aprobada en una orden de alquiler, para reservar los equipos sin volver a digitar datos. |
| HU05 | Como vendedor, quiero registrar clientes (persona natural o empresa con RUC) y sus obras, para tener sus datos ordenados y accesibles. |
| HU06 | Como vendedor, quiero registrar la dirección de entrega y verla en un mapa, para que el chofer ubique la obra sin confusiones. |
| HU07 | Como vendedor, quiero registrar llamadas, mensajes y notas de cada cliente (con su consentimiento), para contar con el historial de contacto. |
| HU08 | Como chofer, quiero actualizar el estado del alquiler (en camino, entregado, devuelto), para que la empresa tenga seguimiento de cada equipo. |
| HU09 | Como cliente, quiero consultar el estado de mi alquiler, para saber dónde está mi equipo y cuándo debo devolverlo. |
| HU10 | Como cliente, quiero recibir notificaciones y recordatorios por WhatsApp o correo, para estar informado sin tener que llamar. |
| HU11 | Como cliente, quiero solicitar una cotización y reservar desde la aplicación, para no depender de llamadas o mensajes manuales. |
| HU12 | Como usuario del sistema, quiero iniciar sesión según mi rol, para acceder solo a las funciones que me corresponden. |
| HU13 | Como administrador, quiero configurar tarifas por día, semana o mes, flete, descuentos y garantía, para que las cotizaciones se calculen automáticamente. |
| HU14 | Como administrador, quiero consultar reportes de alquileres y equipos, para tomar decisiones del negocio. *(Fase 3)* |
